# Knowledge Vault: Structural Protein Biology & AI Design

Welcome to the **Knowledge Vault**! This repository serves as a open-access knowledge base for structured technical notes gathered from leading seminars in the structural biology and computational protein design space. 

Complex academic presentations, wet-lab pipelines, and machine learning architectures are translated into simple, scannable, and high-yield insights for the computational biology community.

## Core Themes Covered in Natasha Seelam talk
* **Data Scale Bottlenecks:** Addressing the lack of non-binding/negative data via open-source datasets (e.g., `open-alphaseq`).
* **Metric Inversion:** Unpacking why standard structural confidence metrics (ipTM, ipSAE, pLDDT) fail to correlate with physical binding affinity.
* **Synthetic Diversity:** Utilizing synthetic epitopes (SEPIA, ABACUS) to eliminate model training bias.
